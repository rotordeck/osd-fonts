# Pixel / bitmap fonts convertible to Betaflight MAX7456 analog OSD fonts

Catalog of true pixel fonts that fit the 12×18 OSD cell (≈10×16 usable ink area after the
1px outline), covering characters 0x20–0x5F. Grouped by licence tier, then a short list
of borderline/rejected fonts and further sources.

**Verification (2026-10-24):** every direct-download URL marked "verified" was fetched and
the file inspected — archives were opened and listed, BDF headers parsed, PNG/BMP sheets
viewed, and TTF/OTF/TTC files parsed with fonttools. For every auditable file I confirmed
the full 0x20–0x5F character set is present (none missing). Rows marked **UNVERIFIED** are
itch.io free downloads that require an interactive checkout, so no direct file URL could
be confirmed. Licences were read from the bundled licence file or the author's own page.

Excluded per your list: Unscii, ZX Spectrum Strict, Public Pixel, Minimal 3x5/5x5/5x7,
Kenney KenPixel (all variants), Boxy Bold, Tom Thumb, the Px437/Bm437 Oldschool PC pack,
and the GrafX2 font collections.

Native sizes marked "≈" were derived from measured glyph outlines/rendering and are
approximate; sizes without "≈" come from the font's own BDF/metadata or documentation.

## Checked and rejected (for your notes)

- **16-bit Gilded** (OpenGameArt, CC0, artisticdude) — attractive golden RPG serif, but the punctuation set is incomplete (no comma, parentheses, etc.), failing the 0x20–0x5F requirement.
- **Jacquard 12** (Google Fonts, OFL) — pretty Victorian pixel serif, but glyphs measure 13–14px wide: does not fit a 10px-wide cell.
- **Doto** (Google Fonts, OFL) — dot-matrix with round dots (ROND axis), not square pixels; borderline against your "true pixel font" criterion.
- **PA5 / "5x5 low pixel font"** (OpenGameArt, CC0) — the author describes it as "latin letters only"; no punctuation set, failing the 0x20–0x5F requirement.
- **7x4 font** (OpenGameArt, CC0, jobromedia) — source PNGs are anti-aliased/blurry, not crisp 1-bit. (broddmin 5x10, listed above, is the crisp 5×10 extension of this font by the same lineage.)
- **Tamsyn** — original author site is gone; Tamzen (listed above) is the maintained derivative of the same design — count them once.

- [Tecate/bitmap-fonts (GitHub)](https://github.com/Tecate/bitmap-fonts) — large curated collection of BDF/PCF bitmap fonts with a licence table; the single best next stop.
- [amcchord/fonts-for-e-ink (GitHub)](https://github.com/amcchord/fonts-for-e-ink) — curated mirrors of ~25 pixel fonts (Cozette, Spleen, Tamzen, Galmuri, DotGothic16, …) with per-font licences.
- [ericoporto/pixel-utf8-fonts (GitHub)](https://github.com/ericoporto/pixel-utf8-fonts) — pixel fonts packaged for game engines.
- [OpenGameArt font search](https://opengameart.org/art-search-advanced?keys=font) — filter by CC0 licence; CC0 glyph sheets and TTFs.
- [itch.io free game assets, fonts tag](https://itch.io/game-assets/free/tag-fonts) — filterable collections of free/CC0 pixel fonts (downloads are interactive).
- [Google Fonts](https://fonts.google.com/?category=Display) — more OFL pixel families (e.g. Jersey 20/25, Jacquard 24, Handjet); search "pixel".
- [Font Library](https://fontlibrary.org/en/catalogue?category_id=12) — CC0/OFL bitmap-style fonts (e.g. Pixel Operator).
- [Aminet (Amiga)](https://aminet.net/search?query=bfont) — Amiga bitmap font archives (many freeware).
- [style64.org](https://www.style64.org/) — C64/PETSCII typefaces (restrictive licence).
- [unifoundry.com](https://unifoundry.com/unifont/index.html) — Unifont family and tools.
